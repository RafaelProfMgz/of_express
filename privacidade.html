Política de privacidade

Dados coletados. Nome, email, telefone, tipo de usuário e dados das vagas. Não coletamos dados de pagamento diretamente no site.

Uso. Organização do grupo de diaristas, match, agendamento e repasse de pagamento. A admin pode excluir dados a pedido.

Compartilhamento. Dados de contato das vagas são visíveis publicamente para facilitar a contratação. Dados de login são protegidos.
